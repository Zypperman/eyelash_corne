Eyelash Corne layer RGB emulator

Simulates ZMK v0.3.0 underglow (the same 50 ms tick and math as the firmware) with this repo's per-layer module. Pick a color for each layer, then copy the result into config/layer_rgb.dtsi.

Layers

Click a row to edit it. Hold works like a &mo key (or hold 1–4 on your keyboard); Toggle works like &tog. Holding number and utility together turns on config (the keymap's conditional layer). The highest active layer with a color wins. Layers set to "no color" fall through to the next one down.

Keyboard settings

ZMK scales your layer brightness into CONFIG_ZMK_RGB_UNDERGLOW_BRT_MIN/MAX (0–100% unless you set them in config/eyelash_corne.conf). The LED count is set by chain-length (7 per half in eyelash_corne.dtsi) and changes how wide the Swirl rainbow looks. Screen boost only brightens this preview; it doesn't change the config. LED positions are an approximation.
